# zyto-landing

Landing page statique de Zyto (bêta privée), prévue pour GitHub Pages.
HTML + un seul fichier CSS : pas de JavaScript, pas de build, aucune dépendance, aucune ressource externe.

- `index.html`, `mentions-legales.html`, `404.html` : les trois pages ; `assets/css/style.css` : tous les styles.
- `assets/fonts/` : Inter et Space Grotesk (woff2 variables, sous-ensemble latin, licence OFL jointe).
- Aperçu local : ouvrir `index.html` dans un navigateur.
- Les textes viennent du document de contenu validé ; toute modification passe par Tudor.
- Avant mise en ligne : conserver `noindex` tant que la bêta est privée.
